# GENERAL RECOMMENDATIONS
    General coding is done in jupyter notebook
    
    Coding is done via small tasks, editing only small part of file,
    or one function.
    
    For every change you make to code, you must create a corresponding
    notebook cell with a quick test function.
    For example, to clarify previous rule - suppose that you are writing a function that
    changes one array schema to another like [ [prompt, completion] ] -> [ {"prompt": prompt, "completion": completion}]
    Then you need to create a cell that uses the function that you've read on a test json, prints input and output, and checks that values are equal to each one another
